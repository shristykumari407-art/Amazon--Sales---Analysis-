
Amazon Sales Analysis Project

Project Overview

This project analyzes Amazon sales data to understand sales trends, profitability, and product category performance.

Tools Used

- Microsoft Excel
- Microsoft Power BI

Key Performance Indicators

- Total Sales
- Total Profit
- Average Order Value
- Profit Margin

Dashboard Insights

- Monthly Sales and Profit Trend
- Category-wise Units Sold
- Sales and Profit Analysis

Files Included

- Excel file containing the sales dataset
- Excel file containing the interactive dashboard

Objective

To analyze sales data and present meaningful business insights using data visualization.
